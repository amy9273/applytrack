# ApplyTrack — Project Overview

ApplyTrack is an AI-powered internship application organizer designed to eliminate manual tracking for students managing internship applications across multiple Gmail accounts.

## Core Problem
- Internship applicants apply through numerous channels and maintain 2 to 3+ different Gmail accounts (personal, university, professional).
- Critical recruitment information (acknowledgments, assessments, technical exams, interview invitations, OJT/MOA requirements) is fragmented.
- Manual spreadsheet tracking requires redundant manual data entry and often falls out of date.

## Solution
1. **Multi-Gmail Connectivity**: Connect 1, 2, or 3+ Gmail accounts with read-only access.
2. **Selective Recruitment Querying**: Target only recruitment communications, preserving privacy and keeping personal emails out.
3. **Automated 12-Category Classification**:
   - Application Confirmation
   - Application Update
   - Interview Invitation
   - Interview Confirmation
   - Assessment Invitation
   - Assessment Instructions
   - Assessment Confirmation
   - Final Interview
   - Rejection
   - Acceptance
   - OJT / MOA Requirements
   - Other Recruitment Communication
4. **Structured Information Extraction**: Company, position, schedule dates, times, meeting links, deadlines, HR contacts, and next steps.
5. **Centralized Hub & Application Tracker**: Unified view with automatic application clustering, eliminating manual entry.
